# RBMK-1000 · 控制棒动态壁纸

以切尔诺贝利反应堆控制棒阵列为原型的 **Android 动态壁纸**。
709 根控制棒随**本机正在播放的音乐**起伏，可显示当前歌曲名。

> 本项目是 [Reactor Audio Visualizer](https://github.com/wzk112/reactor-audio-visualizer)的 Android 移植衍生作品。
> 控制棒的几何与等距投影算法移植自原项目，详见 [LICENSE](LICENSE)。

## 功能

| 功能 | 说明 |
|---|---|
| **动态壁纸** | `WallpaperService` 绘制，约 60fps |
| **跟随系统音频** | `AudioPlaybackCapture` 采集系统混音（不是麦克风）|
| **显示歌名** | `NotificationListenerService` 读取正在播放的曲目，可开关 |
| **实时频谱图** | 256 段频谱 + 频率增益曲线可视化 |
| **参数调节** | 15 个可调参数，实时生效 |
| **律动模式** | 无音乐时的 5 种待机动画（含模拟失控）|
| **可选背景图** | 动态壁纸会取代原壁纸；选一张自己的图当底，控制棒浮在其上 |
| **位置/大小** | 在预览里单指拖动、双指缩放，按目标屏幕比例所见即所得 |

## 可调参数

**强度类**：灵敏度、平滑度、噪声门限、响应曲线 γ、最大高度、基础高度
**频率类**：频率倾斜（dB/oct）、低频增减（dB）、频谱下限、频谱上限
**视角类**：视角角度、俯视倾角、缩放
**位置类**：水平位置、垂直位置

## 律动模式（无音乐时）

| 模式 | 效果 |
|---|---|
| 关闭 | 回落到基础高度并静止 |
| 波浪 | 从中心向外扩散的柔和波纹 |
| 呼吸 | 整场缓慢同步起伏 |
| 脉冲 | 快速向外扫过的同心波 |
| 失控 | 每根棒独立无规律抖动 + 偶发爆发 |

另可勾选「强制演示」，忽略音频直接观察律动模式。

## 构建

本仓库自带 GitHub Actions，推送后自动编译：

```
Actions → 最近一次 "Build APK" → Artifacts → rbmk-1000-debug-apk
```

本地构建（需 JDK 17 + Android SDK 34）：

```bash
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

### 关于签名

仓库内提交了固定的调试密钥 `keystore/debug.keystore`（口令 `android`），
目的是让每次 CI 构建的 APK **签名一致**，从而支持覆盖安装。
这只是调试签名，不可用于正式发布。

## 安装与使用

1. 安装 APK
2. 打开 App，完成三件事：
   * **授权系统音频** —— 系统弹「开始录制或投射屏幕」时确认
   * **通知使用权** —— 用于读取歌名（可跳过）
   * **设为动态壁纸** —— 在系统壁纸选择器中选中它
3. 可选：选择背景图、调参数、调位置和大小

## 关于权限：为什么需要「录制屏幕」

Android 把「采集本机播放的音频」这个能力绑定在 `MediaProjection`（媒体投射）
接口上，系统授权框统一写作「录制或投射屏幕」。

本应用**只使用其中的音频通道**：不读取画面、不录屏、不保存、不上传任何数据。

授权是会话级的：手机重启或应用进程被杀后，需要重新授权一次。

## 关于「透明背景」

Android 的动态壁纸会**取代**原静态壁纸，画成透明并不会露出旧壁纸（下面没有东西）。
想要「浮在自己壁纸上」的效果，请使用 App 内的**选择背景图**功能。

## 外屏（Z Flip 系列）

在 **Good Lock → MultiStar → 启动器小部件** 中允许本应用，即可在外屏打开。

> 三星外屏是否接受第三方**动态壁纸**取决于机型与 One UI 版本，需自行实测。
> 预览支持切换到外屏比例（720×748），保证位置与大小和外屏实际效果一致。

## 技术结构

| 文件 | 作用 |
|---|---|
| `RodArray.kt` | 控制棒几何 + 等距投影 + AGC + 律动模式 |
| `ReactorRenderer.kt` | Canvas 绘制（金属配色）|
| `ReactorWallpaperService.kt` | 动态壁纸引擎，60fps 绘制循环 |
| `AudioCaptureService.kt` | AudioPlaybackCapture 前台服务 + FFT 频谱 |
| `SpectrumBands.kt` | 频段划分与频率增益（服务与可视化共用）|
| `SpectrumView.kt` | 实时频谱 + 增益曲线控件 |
| `PreviewView.kt` | 可拖动/缩放的实时预览 |
| `MusicListenerService.kt` | 通知监听 → 歌名/歌手 |
| `MainActivity.kt` | 授权、参数、预览 |
| `LicensesActivity.kt` | MIT 许可全文（再分发合规要求）|

## 已知限制

* 系统音频采集依赖 `MediaProjection`，授权为会话级，重启后需重新授权
* 部分 App 会主动禁止被采集（如 DRM 音频），此时该 App 的声音不会驱动画面
* 未做正式签名与混淆，`debug` 构建仅供个人使用
